## About
 
I design and run infrastructure that is automated end to end, observable by default and boring in production. I care about how systems behave under load and under failure, from the kernel and the network up to the deployment pipeline, and about turning every manual step into something repeatable.
 
## Focus
 
- Reproducible infrastructure, defined as code and reviewed like code
- Delivery pipelines that take a commit to production without ceremony
- Containers and orchestration as the foundation for every workload
- Monitoring, tracing and alerting that explain what is actually happening
- Networking, security and performance, all the way down to the Linux layer
